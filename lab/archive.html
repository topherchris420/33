Data provenance

Each derived view pins the SHA-256 of the exact input bytes it was generated from. python tools/export_lab_data.py --check fails if any input changes without the view being regenerated. Canonical records (evidence, protocol, model outputs) are read directly, not copied.

04

Source rights audit: the F-117A OCIP supplement

Historical aerospace engineering
Document
OCIP Supplement to the Utility Flight Manual, USAF Series F-117A (TO 1F-117A-1A), Issue B, 3 February 1992, 84 pages.
Distribution
Its distribution statement limits distribution to U.S. Government agencies and refers other requests to the issuing office.
Reproduction
Its list of effective pages states that reproduction of its information or illustrations for non-military use is not permitted.
Handling
It carries handling-and-destruction and disclosure notices, and describes operational procedures and weapon-system equipment.

Decision

  • The scanned document is not committed, published, linked, or redistributed.
  • No text, figure, symbol, display format, procedure, value, or diagram from it appears anywhere in the laboratory.
  • The Instrumentation Lab teaches general, widely published human-factors principles — information pipelines, stale and missing data, failure dependencies — with original synthetic examples, explicitly labelled as not an F-117A format.
  • The workshop's aircraft miniature is an original low-poly prop of a retired, publicly displayed shape, with a placard saying it is not a Project 33 component and carries no data from the manual.
  • No technical compatibility between the aircraft and Project 33 is implied anywhere.

Recommendation: keep the PDF out of the repository and its history. If the document is needed for future work, obtain written redistribution permission first.

07

Command isolation

The laboratory is a static, read-only site. It has no WebSocket, WebSerial, WebUSB, or WebBluetooth code and fetches only same-origin files. tests/test_lab_isolation.py scans every laboratory page and script and fails if any of those APIs, a fetch to another origin, or an externally hosted script appears. Firmware, interlocks, and the evidence record are untouched by this work.
