Generation prompt:

> Use case: stylized-concept. Asset type: wide editorial cover for the README of Project 33, an open engineering evidence archive by Vers3Dynamics. Create a premium, understated research-publication cover, approximately 2400 by 1000, landscape. Visual: on warm off-white cotton paper, a beautifully composed still-life of several thin graphite-gray archival sheets and frosted glass sheets floating in a shallow axonometric stack on the right; the uppermost sheet contains only an abstract unlabelled ring and sparse small dots as a metaphor for an incomplete record, never a real scientific chart. Very fine soft shadows, tactile paper grain, quiet red-orange index tabs, an elegant museum catalogue feeling, practical editorial typography, very generous negative space. On the left, exact black text 'PROJECT 33' in large beautiful condensed modern sans-serif type, then below in smaller text 'THE RECORD IS THE EXPERIMENT.' Top left very small 'VERS3DYNAMICS'. Bottom left small 'OPEN ENGINEERING RECORD'. No other text. Typography must be precise, high contrast, and exceptionally legible at GitHub README size. Palette: warm ivory, graphite, a single muted vermilion accent. This is conceptual artwork, not evidence or a UI screenshot. No weapons, rockets, machinery, schematic components, measurements, graphs, circuitry, fake dashboards, glowing gradients, sci-fi imagery, logos or watermarks. The composition should look like a meticulously art-directed printed monograph cover, not generic AI concept art.
